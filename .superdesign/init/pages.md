# Page Dependency Trees

**This file is the SINGLE SOURCE OF TRUTH for `--context-file` selection.**
If a file appears in a page's tree, it must be passed when designing that page.
Generated by recursive local-import tracing (relative + `@/` alias; node_modules
skipped). `*(seen)*` marks a file already expanded earlier in the same tree —
it is still a dependency, just not re-expanded.

Every page also renders inside `src/app/layout.tsx` (header + footer), and every
design command must additionally pass:
- `src/app/globals.css` (the Tailwind v4 `@theme` config — 678 lines, passes whole)
- `.superdesign/design-system.md`

There is **no `tailwind.config.ts`** in this project.
